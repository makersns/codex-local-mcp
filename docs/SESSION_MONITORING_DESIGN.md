# Codex Local MCP 会话活动监测

更新日期：2026-11-23（Asia/Shanghai）。适用版本：0.6.0。作者：Sugar。

服务内存统计、私有 IPC 和桌面快照已经实施，并通过完整后端回归。原生概览使用这些真实聚合数据；真实 ChatGPT 隧道是否携带会话元数据，需要以最终连接验收为准，不能用预览数据代替。

## 用户看到的三项指标

| 指标 | 准确定义 |
| --- | --- |
| 正在调用的会话 | 至少有一个工具请求尚未结束的不同已识别会话数；同一会话并发请求只计一次 |
| 最近 10 分钟活跃会话 | 在最近 600 秒发起过工具请求，或者当前仍有未结束请求的不同已识别会话数 |
| 运行中任务 | 本机受管命令中仍在运行的任务数，独立于会话和工具请求 |

`run_command` 返回后，命令可能继续运行，但工具请求已经结束。因此长时间运行的开发服务增加的是“运行中任务”，不能让发起它的会话永久成为“正在调用”。

匿名明细最多展示 32 项，只包含本次运行的序号、当前调用数、最近请求时间、操作名和已配置的工作区 ID。界面可将已知工作区映射为授权文件夹名称；不需要聊天标题、正文或用户身份。

## 能知道什么，不能知道什么

官方 `_meta["openai/session"]` 可以将同一个 ChatGPT 会话的工具调用关联起来。它随请求提供，并不构成持续在线心跳，也不提供可靠的聊天窗口关闭事件。

因此本功能显示当前执行与最近活动，不宣称精确知道多少个空闲聊天窗口仍在线。没有新调用只代表观察期内没有工具活动，不能证明会话已经断开。

当前固定 MCP Python SDK 2.3.0 中，`ctx.request_context.meta` 是字典：

```python
meta = ctx.request_context.meta
session_id = meta.get("openai/session") if isinstance(meta, dict) else None
```

Context 由 SDK 注入，不由模型填写。现有 15 个公开工具的输入 schema 不包含 Context 或“会话 ID”参数，也没有为了界面统计新增公开 MCP 工具。

## 未识别来源与覆盖范围

缺失、空值、错误类型、控制字符或超过 1024 UTF-8 字节的标识按未知来源处理，原工具仍正常执行。

未知来源有两个请求计数：当前尚未结束的调用，以及最近 600 秒开始的调用。它们不是未知会话数量，不能把所有未知请求合成一个会话，也不能按请求次数推测聊天数。

当有未识别来源时，界面明确说明统计只覆盖已识别部分；没有已识别会话时展示“来源未识别”。后台不运行、版本过旧或查询失败时，返回 `available:false`，各项计数为 `null`，显示无数据状态而不是假零。

所有统计从当前后台进程启动时开始。重启会更换运行标记、清空统计并重新编号，不保留跨运行期会话身份。

## 实现结构

| 位置 | 职责 |
| --- | --- |
| `server/src/sugar_local_mcp/activity.py` | 有界线程安全的内存聚合、未知来源、时间窗口和覆盖标志 |
| `server/src/sugar_local_mcp/server.py` | 15 个工具接收 SDK Context，在统一 invoke 入口开始和结束统计 |
| `server/src/sugar_local_mcp/processes.py` | 只读汇总仍在运行的受管命令 |
| `server/src/sugar_local_mcp/diagnostics.py` | 通过现有私有 Unix socket 提供 activity_snapshot |
| `desktop_api.py` | 将有限、已验证的聚合结果加入 snapshot.activity；兼容旧后台 |
| `macos/` | 概览摘要、匿名明细、本地化提示及无数据状态 |

活动查询使用现有本机诊断通道，截止时间为 1 秒，不增加公开网络监听端口。查询使用独立状态通道，不因文档诊断通道繁忙而阻塞整页。GUI 轮询不计为远端会话活动，不生成会话活动审计记录。

成功、异常、取消和审计失败均通过 `finally` 结束当前调用计数。有效期使用单调时钟，展示时间使用 UTC 时间戳并由界面按用户地区格式化。长于 600 秒且仍未结束的请求继续保留在当前和近期会话统计中。

完整字段、可空规则和示例见 [桌面 API v1 契约](DESKTOP_API_V1.md)。

## 隐私与内存边界

每个有效匿名标识在处理当次请求时，立即使用本次进程独立随机密钥生成 HMAC。只将摘要保存在内存注册表，不把原始标识、摘要或该密钥写入磁盘、日志、IPC 或界面。

注册表最多保留 256 个已识别会话、4096 个未知请求开始时间及 32 条可见明细。过期且空闲的记录被清理；当前请求优先保留。容量不足时明确返回部分覆盖状态，不静默丢失后仍声称统计完整。

活动数据不保存工具参数、命令内容、文件正文或文件路径。只有已配置工作区的 ID 可进入摘要；非法工作区字符串被排除。会话元数据仅用于展示，不能决定认证、文件权限或任务所有权。

## 官方来源

[OpenAI Plugins Reference](https://developers.openai.com/plugins/reference) 定义 `openai/session` 为同一 ChatGPT 会话工具调用的匿名关联元数据。核查日期：2026-11-23。

“最近 10 分钟”的时间窗口、内存 HMAC、容量限制和界面指标属于本项目的实现选择；官方字段本身不能证明聊天窗口持续在线。
