## 2. 产品与交互决策

- 原生 macOS 单窗口，左侧固定导航，主体为概览/表单/列表。
- 正式品牌 Codex Local MCP；作者在侧栏底部及“关于”显示 Sugar，不混用Sugar产品标题。
- 默认浅色白灰与克制的靛紫强调色，细边框、清晰排版、正常密度；使用原生文件夹选择器、键盘导航、可访问性标签。
- 启动页突出本机是否就绪、已授权文件夹、常用入口；无虚构CPU/调用量仪表盘。
- 主显示文件夹实际名称；项目ID自动生成、保持稳定，归入“更多设置”。不要求普通用户记ID规则。
- 新目录默认可读取、允许文件编辑、不默认运行本机命令；已有权限完全保留。
- 编辑与运行两个权限有通俗说明；必须明确运行命令也可修改文件，不能误称“写入关闭+执行开启”为只读。
- 首次配置在同一页完成电脑名称、连接信息、选择第一个文件夹，最后一次“保存并连接”。
- 已有密钥显示钥匙串状态，提供“更换密钥”；留空明确表示沿用，不返回密钥。
- 保存的明确动作是“保存并重启/保存并连接”，显示正在运行的任务会中断；不会因切换开关立即重启。
- 页面切换/关闭遇到未保存修改时提供保留编辑或放弃的明确选择；取消不落盘。
- 保存后启动失败必须分别说明“设置已保存”和“连接未成功”，给出下一步，不丢弃用户编辑。
- 已存在连接只读展示；启动新UI不会自动升级/停止正在运行的连接。
- 状态“本机已就绪”只指本机隧道，ChatGPT端到端状态必须来自真实调用，不能伪造成功。
- Chrome集成属于独立连接；展示使用指引，不模拟其连接/授权状态。
- 环境检查和系统权限均手动触发，区分未检查、不可达、缺少依赖和未授权。
- 运行记录限量展示并脱敏；普通错误优先给出原因和可操作的恢复入口。

### 页面范围

1. 连接概览：本机状态、启动/停止/重启、文件夹概况、使用指南。
2. 项目文件夹：添加、选择、编辑、更换、权限、移除访问、ID高级项。
3. 连接设置：初次引导/既有连接、电脑名称、Tunnel ID、密钥状态/替换。
4. 环境检查：Office依赖检测与基础文档验证、可选系统权限检查/明确申请或打开设置。
5. 运行记录：固定日志限量读取、刷新、复制脱敏信息、打开日志目录。
6. 使用帮助/关于：配置步骤、Chrome集成、作者、版本、仓库入口。

## 3. 架构

采用 SwiftUI + AppKit 原生界面（最低 macOS 13）和既有Python后台管理逻辑。无需Electron、Node、额外Web服务或监听管理端口。

- macos/：原生App入口、UI模型、样式、页面、后台进程客户端。
- desktop_api.py：一次性stdin JSON → stdout JSON的控制API。
- desktop.py：继续负责既有受管连接生命周期和配置兼容。
- workspace_config.py：继续负责完整工作区文档校验、权限、原子保存与并发检查。
- security_store.py：保留钥匙串接口，新增不读取密钥内容的存在性查询。
- bootstrap.sh：异步准备/复用Python运行环境；不会自动切换已有隧道。
- build-macos.sh/install-app.sh：原生构建、签名校验、安装、同版本修复与防降级。
- docs/DESKTOP_API_V1.md：冻结UI与Python间契约。

客户端不执行任意shell拼接，不把密钥放入命令行、环境日志、JSON响应或明文配置。命令名和打开的系统链接采用固定允许集合。

## 4. 兼容与数据可靠性

以下内部标识保持兼容，不因品牌调整丢失现有配置：

- ~/Library/Application Support/Sugar Local MCP Desktop
- com.sugar.local-mcp.desktop 及 runtime launchctl label
- 既有Keychain service/account
- Python模块 sugar_local_mcp 和旧CLI兼容入口

这些仅是内部兼容实现，不用作新版UI产品名。新增Codex可见入口，作者Sugar。

保存时必须保留完整workspace_document中的自定义限制/其他受支持字段，避免从可见表单重建而丢字段。使用短时control.lock与覆盖settings+workspaces的revision；发现外部修改时提示重新加载，不自动覆盖。首次setup一次校验全部配置；I/O中途失败需恢复原文件；已保存但连接失败则明确报告保存结果。

应用不通过权限修改、替换TLS策略或读取真实密钥来简化测试。原有只读/写入/执行安全边界和受管进程所有权检查保持有效。

## 6. 验收标准

### 自动化

- 既有desktop与MCP server测试全部通过。
- JSON协议拒绝未知动作、非法输入和过大请求；敏感值不回显。
- 目录增删改、重复ID、不存在路径、32个上限、中文/空格路径。
- 自定义配置字段保留；stale revision无写入无重启。
- 初次setup完整验证；空密钥沿用；密钥存在性查询不返回内容。
- 保存成功但重启失败的状态可恢复；未保存草稿不会被轮询覆盖。
- 非本应用监听进程不停止；状态仅证明本机就绪。
- 诊断手动触发，日志有固定文件范围、长度限制与脱敏。
- Swift协议解码、ID建议/权限文案/状态映射和preview隔离验证。
- 构建签名、版本、作者、bundle资源齐全；隔离目标安装/重复安装/防降级。

### 原生UI与真实运行

- 审核图核心布局在实际原生窗口中成立，正常窗口与窄窗口无重叠/裁切。
- 所有按钮可操作，文件夹选择器/取消/保存/未保存提示/错误恢复走通。
- 首次配置与既有配置两种路径均可用。
- 截图保留实际页面（使用示例数据的截图明确标识测试预览）。
- 新版安装后保留旧用户配置和现有权限，确认作者与品牌。
- 测试和打包阶段不打断当前MCP；最终切换使用独立受管方式并验证新版本回连。
