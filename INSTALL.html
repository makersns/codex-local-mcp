让 AI 在你的电脑上工作

选择文件夹，配置一次连接，即可在 ChatGPT 中处理本地文件和开发任务。

0.6.0 · macOS 13 及以上

首次使用，四步完成

  1. 打开 Codex Local MCP.app

    应用会安装到你的 Applications 目录，并准备所需运行环境。首次准备需要网络，完成后显示原生配置页面。

  2. 填写连接信息

    给这台 Mac 起一个易于识别的名称，再填入连接 ID 和连接密钥。页面提供获取入口；密钥只保存在本机登录钥匙串。

  3. 选择要使用的文件夹

    点击“选择文件夹”，确认是否允许编辑文件、运行任务，然后“保存并连接”。项目标识会自动生成，需要时可在更多设置中调整。

  4. 在 ChatGPT 中确认可用

    选择对应连接，让 ChatGPT 列出项目文件夹并读取一个 README。应用中的“本机已就绪”表示本机隧道可用，实际工具调用成功后才说明完整链路已通。

连接信息在哪里获取？

在 隧道设置 创建或选择隧道，并将其关联到目标 ChatGPT 工作区；按照 官方连接指南 准备适用的 Runtime key。

每台 Mac 使用不同的连接 ID。Runtime key 需要对应隧道的 Tunnels Read + Use 权限。

已有密钥无需重复填写，页面会显示保存状态；需要替换时点击“更换密钥”。

文件夹权限，一眼看懂

  • 阅读文件：读取已选文件夹中的内容。
  • 编辑文件：允许文件工具创建和修改文件。
  • 运行任务：允许运行开发服务、测试及本机命令。

新文件夹默认允许编辑，运行任务默认关闭；升级保留原有权限。

运行命令使用当前 macOS 用户的权限，也可能修改文件。关闭“编辑文件”不会限制已经允许的命令。

修改设置后统一保存；切换页面前可以继续编辑或放弃更改。保存并重启会影响正在运行的任务，请先完成当前工作。

关闭窗口后，后台连接继续运行。需要停止时，在连接概览选择停止连接。

网页调试，配合 Chrome 集成

Codex Local MCP 负责文件和本机进程，ChatGPT 的独立 Chrome 集成负责打开页面、操作表单和检查结果。请在同一会话中选择连接到同一台 Mac 的两项集成。

使用多台 Mac 时，切换本机连接不会自动切换 Chrome 设备。可以先打开该 Mac 本地项目的实际页面，确认设备对应。

普通文件和终端功能无需开启屏幕录制或辅助功能；环境页面中的系统权限检查是可选操作。

从旧版升级

新版沿用已有文件夹列表、权限、隧道设置和钥匙串。首次打开只准备新版环境，不会主动停止正在使用的旧连接。

确认当前任务完成后，在应用内保存并重启或重启连接。随后在 ChatGPT 刷新对应插件，再调用工具确认服务版本。

从源码构建与安装

保留完整 Source 文件夹，双击 Install_Codex_Local_MCP.command。源码构建需要 Apple Command Line Tools；普通使用直接打开预编译 App 即可。旧名称的安装脚本仍可转发到新入口。

系统与发布说明

原生界面支持 macOS 13 及以上，构建包包含 Apple Silicon 和 Intel 两种架构。实机验证范围以发布验证记录为准。应用目前使用 ad-hoc 签名，尚未提供 Apple Developer ID 公证。若系统阻止打开，请确认来源并使用系统提供的“隐私与安全性”允许打开流程。

首次安装需要联网下载运行组件。软件不会更改 Gatekeeper、TLS 或系统安全设置；原有设置不会因安装失败而删除。
